Privacy & data opens its own screen (M13). Focus is on the fields: the focused row takes the selection style (fill + orange edge) and carries its own action at the right, muted (↵ edit; while editing, its value becomes a lavender composer with the old value and the hint reads ↵ done · esc cancel). The category keys are muted and the current category keeps only the fill. A dim note under a field says what goop does with it. Form actions live in the single status line, first, only while there are unsaved changes (no second bar): ● 1 unsaved change and the changed field on the left, ctrl+s save (green), ctrl+z undo, ctrl+d discard on the right; the changed label also gets a ●. Nothing is applied until ctrl+s, and the form keys use ctrl so they also work while typing in a field; esc back with unsaved changes opens the ask below instead of dropping them silently. Without unsaved changes the status line shows only navigation (↑↓ move · tab categories · esc back). The pane foot says settings are stored encrypted and never sent anywhere. Costs a full screen that hides the chat, and fields with long values (keywords) are edited one line at a time.
