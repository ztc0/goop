Full screen: ? opens help like M7/M8 (title breadcrumb, one status line, no key-hint line under the header) and remembers where you came from: the first section, Keys here, shows only the keys of that screen (here: from Offer detail), grouped Move · Act · Views as a two-column table, key bold --text and action muted, with the primary action ↵ in green, matching M2's offer detail. A search line at the top (/ search help) filters keys, commands and symbols in every section at once. The symbols and color legend that used to sit on each screen now lives here, in Symbols & colors (shown below the screen next to Global keys); the right pane lists the few symbols seen on the screen you came from as a fourth group, Symbols, in the same key table, instead of a separate bar (like the legends removed from M8 and M14). Help does not repeat the command list: Commands is a pointer to the command palette (ctrl+p), which is the one full, searchable list, so help never drifts from it. Trades a quick overlay you can read over the screen for a full screen with sections: more room and one home for the legend, but you lose sight of the screen you asked about and need esc to return to it.
